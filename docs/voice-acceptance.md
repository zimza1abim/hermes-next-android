# 인수 기준 (AC) — hermes-voice-plan.md 고정

기획서의 「단위 테스트」 표와 「기기 시험」 18개를 그대로 수용 기준으로 옮긴 것. 형식: **무엇을 하면 → 무엇이 관찰된다**. 판정은 통과/실패/미확인 셋만 쓴다.

## A. 단위 테스트 (소리·네트워크 없이)

| AC | 하는 일 | 관찰되는 것 | 근거(기획서) |
|---|---|---|---|
| AC-01 | 설정 메시지를 만든다 | 직렬화 JSON에 모델·응답 형식(AUDIO)·목소리·한국어 코드·입출력 자막·지시문·`ask_hermes` 선언이 모두 있다 | 3번, 8번 |
| AC-02 | 서버 음성 조각을 읽는다 | `inlineData` base64 → 24kHz/16bit PCM 바이트, 재생 큐에 넣을 조각으로 나온다 | 5번 |
| AC-03 | 입력·출력 자막 메시지를 읽는다 | 자막 모델(역할, 텍스트, 확정 여부)에 순서대로 쌓인다 | 7번 |
| AC-04 | 함수 호출 메시지를 읽는다 | callId·함수 이름·인자(요청문)가 꺼내진다 | 9번 |
| AC-05 | 끼어들기 신호를 읽는다 | `interrupted` 이벤트가 나오고 재생 큐를 비우는 효과가 발생한다 | 6번 |
| AC-06 | 종료 예고를 읽는다 | 남은 시간(초)이 담긴 이벤트가 나온다 | 18번 |
| AC-07 | 재개 핸들 업데이트를 읽는다 | `resumable=true`일 때만 핸들을 저장한다 | 18번 |
| AC-08 | 이상한 메시지를 넣는다 (모르는 키, 빈 `{}`, 깨진 JSON, 타입 불일치) | 상태·재생 큐·핸들이 그대로이고 예외가 밖으로 나가지 않는다 | 프로토콜 |
| AC-09 | 봇이 말하는 중에 끼어들기 신호 | 재생 큐가 즉시 비고 상태가 Listening이 된다 | 6번 |
| AC-10 | Delegating 중 끼어들기 → 늦게 Hermes 답 도착 | 답이 버려지지 않고 결과 전달(낭독)로 이어진다 | 상태 기계 |
| AC-11 | 넘기기 요청 후 90초 경과 | 성공이 아니라 시간 초과 실패 결과가 모델로 전달된다 | 13번 |
| AC-12 | 종료 예고 수신 | Reconnecting으로 가고, 핸들로 재연결 후 Listening으로 돌아온다 | 18번, 19번 |
| AC-13 | Ended로 진입 | 정리 효과가 **정확히 한 번** 발생하고, 그 목록에 마이크·재생·소켓·서비스·타이머가 모두 있다 | 24번 |
| AC-14 | Ended 이후 늦게 도착한 서버 메시지 | 무시되고 상태·효과에 변화 없음 | 상태 기계 |
| AC-15 | 프리셋 3종 × 강도 0~3 × 직접 쓰기 조합 | 항상 붙는 규칙 4개가 하나도 빠지지 않는다 | 16번 |
| AC-16 | 지시문을 조립한다 | 순서가 봇 이름·역할 → 프리셋(또는 직접 쓰기) → 강도 문장 → 항상 붙는 규칙 → Hermes 넘기기 규칙 | 16번 |
| AC-17 | 봇별 덮어쓰기가 있는 설정으로 조립 | 그 봇은 덮어쓴 목소리·프리셋이, 다른 봇은 기본값이 적용된다 | 16번 |
| AC-18 | 마크다운·표·링크·코드블록이 섞인 답을 다듬는다 | 기호·표·URL이 사라지고 코드 블록은 "코드는 화면에 띄웠어요"로 대체된다 | 11번 |
| AC-19 | 아주 긴 답, 빈 답, 공백만 있는 답 | 2000~3000자에서 잘리고, 빈 답은 정해진 짧은 문장이 된다 | 11번 |
| AC-20 | Hermes로 질문을 넘긴다 | 질문에 `surface: "voice-live"` 표시가 있고, 답이 그 턴과 짝지어 돌아온다 | 프로토콜 |
| AC-21 | 넘기기가 실패하거나 시간 초과 | 실패 사실이 그대로 전달되고 "성공했다"는 결과가 만들어지지 않는다 | 13번 |

## B. 기기 시험 (실제 폰)

| AC | 시나리오 | 통과 기준 |
|---|---|---|
| AC-22 | 조용한 방, 스피커로 대화 | 말 끝 → 첫 음성 **1.5초 이내** |
| AC-23 | 스피커 크게 | 봇 목소리를 내 말로 잘못 듣지 않음(자기 발화로 턴이 끊기지 않음) |
| AC-24 | 봇이 말할 때 끼어들기 | **0.3초 안에** 재생 정지 |
| AC-25 | "내 서버 디스크 용량" 질문 | Hermes 실제 도구로 답하고 낭독되며 대화에 남음 |
| AC-26 | 30초 넘는 Hermes 작업 | 기다리는 동안 대화가 이어지고, 끝나면 결과를 알려 줌 |
| AC-27 | 통화 중 승인 요청 | 카드가 뜨고, 허용하면 진행됨 |
| AC-28 | 목소리·말투 변경 | 다음 통화부터 정확히 적용, 미리 듣기와 같음 |
| AC-29 | 봇마다 다른 목소리 | 봇을 바꿔 통화하면 그 봇의 목소리·말투 |
| AC-30 | 화면 끄기, 다른 앱으로 이동 | 통화 유지, 알림에서 종료 가능 |
| AC-31 | 전화 수신 | 멈췄다가 통화가 끝나면 이어짐 |
| AC-32 | 와이파이 → LTE | 재연결 후 대화 맥락 유지 |
| AC-33 | 블루투스 연결·해제 | 소리가 알맞은 장치로 이동 |
| AC-34 | 15분 넘는 통화 | 끊김 없이 이어짐 |
| AC-35 | 키 없음·틀린 키·한도 초과 | 알맞은 안내, 앱 멈춤 없음 |
| AC-36 | 통화 중 대화창 보기 → 복귀 | 통화 유지, "통화 중" 띠로 복귀 |
| AC-37 | 잠금 화면·상태바(Android 통화형 알림) | 통화 시간과 끊기 버튼 표시, 끊기 동작 |
| AC-38 | 귀에 대기 / 떼기 | 화면 꺼짐·수화기 전환, 떼면 복귀 |
| AC-39 | 통화 10번 열고 닫기 | 메모리 증가 없음, 마이크 표시가 남지 않음 |
